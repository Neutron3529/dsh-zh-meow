# 喵体中文

这是一个dsh插件：是基于`zh-cn`的`zh-meow`

这个插件主要有两个用途

其一，插件可以将deepseek的大部分英文提示词翻译成喵体中文，这样可以允许AI不被英文提示词带偏，使得AI有直接使用中文思维链的能力。

> 如果你希望及时检查AI的思考输出，你可以用喵体中文插件，及时制止AI离谱的行为

其二，插件对计划模式有特攻。在计划模式中，当AI向人类提问时，几个备选项的”你“都代表用户，而”我“代表agent。比如用户选择一个`1. 我来重启deepseek harness`，AI会认为这是用户授权AI重启deepseek harness。

> 使用喵体中文之后，喵喵agent会使用「本喵」「人家」之类的称呼来指代自己，用「主人」来指代用户，这时候，用户选择的`1. 本喵来重启deepseek harness`会直接被消歧义。

## 一些微小的改进

据说让AI喵起来的话，可以显著减少AI不说人话的概率。至少我至今为止没有看到一只说”不是而是“的猫娘。
